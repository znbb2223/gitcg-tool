# 牌组码工具（七圣召唤）

**打开就是菜单**：双击/运行 `deckcode.bat`（Windows）或 `./deckcode.sh`（Linux/macOS），
会出现编号菜单：1 解码、2 编辑/编码、3 查询名字/ID、4 30 张同卡、5 3 个同角色、
6 自由填充、7 批量处理、0 退出。

| 文件 | 平台 | 依赖 |
|---|---|---|
| `deckcode.sh` | Linux / macOS / 任意 bash | **只用 bash 内建**，零安装 |
| `deckcode.bat` | Windows（能跑 bat 的机器） | **只用 Windows 自带**：cmd + certutil + cscript |
| `deckcode.html` | 浏览器（手机/电脑双击） | 无 |

## 菜单里能做什么

- **1) 解码**：粘牌组码，逐槽显示「角色/行动牌 + 名字 + ID」；
- **2) 编辑 / 编码**：33 个槽位（3 角色 + 30 行动牌）自由编辑——
  - 查看当前、设置任意槽位（名字或 ID）、填充 30 张行动牌、
  - 30 张同卡 / 3 个同角色快捷、解码粘贴、输出牌组码、清空；
- **3) 查询**：名字或 ID 模糊查表（内置 110 角色 + 527 行动牌）；
- **4/5/6)** 三个快捷生成器；
- **7) 批量**：文本文件每行一组（牌组码或 33 个名字/ID）。

命令行模式也保留（适合脚本）：

```bash
./deckcode.sh decode <牌组码>
./deckcode.sh set <牌组码> 4 猫爪冰摇
./deckcode.sh encode 甘雨 迪奥娜 凯亚 ...（共 33 个）
./deckcode.sh fill 甘雨 迪奥娜 凯亚 <30 张牌>
./deckcode.sh same-card 最好的伙伴！ 甘雨 迪奥娜 凯亚
./deckcode.sh list 甘雨
./deckcode.sh batch 列表.txt
```

Windows 把 `./deckcode.sh` 换成 `deckcode.bat`，参数一样。

## HTML 版

33 个槽位直接输入名字/ID（带补全），或粘贴 33 个（或 30 张牌）一键填充；
粘贴牌组码可解码回槽位；下方对照表点一下填进当前槽位。纯本地，不联网。

## 说明

- 编码会自动挑选校验字节避开敏感词黑名单（与游戏内一致）；
- 牌组码对顺序敏感：顺序不同编码不同，内容相同；
- 「30 张同卡 / 3 个同角色」属非常手段，正式对局可能被拒绝，仅用于测试与娱乐；
- 未知 ID、重名（匹配到多个）都会报错并给候选。
