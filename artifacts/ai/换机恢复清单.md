## 三、装完先验证（3 分钟）

```bash
cd /data/gitcg
# 1. 纯启发式自对打 1 对，看能不能开局
node bin2/ab-value.bundle.mjs --a=heur --b=heur --pairs=1 --lib=data/deck-library.json

# 2. 搜索 vs 启发式 1 对（用 22 维模型基准配置）
node bin2/ab-value.bundle.mjs --a=v1 --b=heur --pairs=1 --budget=150 --depth=10 \
  --lib=data/deck-library.json

# 3. 采集 2 局，确认 v4 格式
node bin2/collect.bundle.mjs --games 2 --shard 0 --shards 1 --out /tmp/t1 \
  --mix heuristic --sample 2 --lib=data/deck-library.json
zcat /tmp/t1/shard-0.jsonl.gz | head -1 | python3 -c "import json,sys;r=json.load(sys.stdin);print('v',r['v'],'ai',r['ai'],'n',r['n'],'e',len(r['e']))"
```

三条都通过 → 环境就绪。

## 四、从哪一步接续（按优先级）

| 顺序 | 任务 | 命令 | 规模/耗时 |
|---|---|---|---|
| 1 | **预算对照**（600ms vs 150ms，被中断） | `bash chain-budget.sh` | 104 局 / 30 分钟 |
| 2 | **预览加速对照**（跳过 rollout 预览 vs 完整） | `bash chain-preview.sh` | 208 局 / 40 分钟 |
| 3 | **搜索标签重采**（v4，双头网络的前提） | `bash collect-v4.sh` | 2,000 局 / 3~4 小时 |
| 4 | 搜索扩样（vs 启发式，从 104 局扩到 500） | `bash chain-heur2.sh` | 400 局 / 1 小时 |

注意：脚本里写死了 `/data/gitcg` 路径和 `bin2/` 子目录，换机后不用改；但 IP 变了要改本机的 SSH 命令。

## 六、安全提醒

- 旧的 `~/.ssh/id_ed25519` 私钥在本机 `/root/workspace/.ssh/`，新机需要把公钥加进 `authorized_keys`，或让云厂商直接注入
