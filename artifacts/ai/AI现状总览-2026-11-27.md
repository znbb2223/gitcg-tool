## 0. 一句话

强度几乎全部来自 **rollout 次数**：规则引擎 + 启发式 + 推演搜索，其余组件（价值网/策略网/查表/记忆/先验/贝叶斯）
实测都接近零收益、默认全关。搜索"偷看对手手牌"的结构性缺陷今天已修好（A 方案，实验侧开关可用，**App 尚未接线**）。

## 1. 架构四层

| 层 | 位置 | 作用 | 状态 |
|---|---|---|---|
| 规则引擎 | `packages/core`（`game.ts`、`preview.ts`、`mutation.ts`…） | 合法动作枚举、结算、动作预览 | 无开关，地基 |
| 启发式评估 | `packages/ai/src/evaluate.ts`（`scoreAction`）、`player.ts`（`AiPlayer`） | 出招打分、搜索的候选先验、搜索关闭时兜底 | 无开关，必开 |

| 可选组件 | `value.ts`（价值网 44 维→64→32→1 tanh）、`policy.ts`（策略网）、`memory.ts`、`ponder.ts`（后台预计算） | 叶评估/排序/缓存 | 全部默认关 |

关键常量：特征 `FEATURE_NAMES` 共 **44 维**（`value.ts`，顺序发布后不可改，旧模型靠维度校验自动回退手工评估）；
价值网约 3.5k 参数、导出 ~50KB；训练用 `packages/ai/tools/train_value.py`（numpy，单线程 BLAS）。

## 3. 有效项（有正收益）

| 项 | 样本 | 结果 | 备注 |
|---|---|---|---|
| 搜索 vs 纯启发式 | 798 局 | **60.7%**（z=6.02） | 重跑后 60.1%（208 局），一致 |
| 跳过 rollout 内预览 | 416 局 | **63.9%**（+13.9 点） | 已上线 worker；重跑 65.2%（207 局） |
| 预算 600ms vs 150ms | 415 局 | **75.7%** | 重跑直接对打 75.0%（208 局） |
| 搜索 @600ms vs 启发式 | 207 局 | **85.5%** | 说明预算还没到顶 |
| 大招计划（缺骰时调和凑大招） | 606 局 | **53.3%**（+3.3 点） | 已上线；扩样到 1,000 局待做 |

**核心规律：rollout 数每翻一倍 ≈ +12~13 点胜率。** 150ms ≈ 1.3 条 rollout、600ms ≈ 5 条、跳过预览后单次成本 112ms → 34ms。

## 7. 实验方法论（复现用）

```bash
# A/B（镜像配对：同牌组同 seed 打两局交换先手）。--offset 分片并行
node bin2/ab-value.bundle.mjs --a=v1 --b=heur --pairs=104 --offset=0 \
  --budget=150 --depth=10 --lib=data/deck-library.json
# 猜牌 vs 旧逻辑（A 侧开 A 方案）
node bin2/ab-value.bundle.mjs --a=v1 --b=v1 --realisticHidden=true \
  --pairs=52 --offset=0 --budget=150 --depth=10 --lib=data/deck-library.json
# 三组重标定 + 猜牌不变量检查（本次用过的脚本）
bash bin2/remote-retest.sh; node bin2/check-hidden.bundle.mjs 0
# 采集（v6）与训练
node bin2/collect.bundle.mjs --games 5000 --shard 0 --shards 4 --out /data/gitcg/traj-v6 \
  --lib /data/gitcg/data/deck-library.json --mix mixed --sample 3 --budget 100 --depth 10
python3 packages/ai/tools/train_value.py --data 'collected/traj-v3/*.jsonl' --out model.json --epochs 30
```

- 输出 `RESULT {...}` 一行 JSON；`error` 计数必须为 0。
- 样本量：100 局误差 ±5%、检测 53% 需 ~2,000 局、检测 55% 需 ~380 局。
- 先跑 `--a=v1 --b=v1` sanity（今天 49.5%，无系统偏差）。
- 跑前确认 `--pairs` × 2 = 目标局数，`offset` 区间不重叠。
- 已知记数 bug 已修：和棋（`winner=null`）以前只漏算不记 `draw`。

## 10. 坑清单（合并 skill 与今天新增）

1. `pkill -f "xxx"` 会杀死自己（命令串含同名文本）→ 用 `[x]xx` 或按 PID。
2. 异步 `createWriteStream` 在长任务里丢数据 → `appendFileSync` + gzip。
3. 采样计数不能用 `samples.length`（push 后不增）。
4. `ab-value.mjs` 早期版本 `selectAction` 从未被调用（AI state 为 null 时提前返回）→ 结果恒 50%。
5. 预览局面字段是 `summon`/`support` 单数。
6. 特征维度变更 → 旧样本/旧模型全废（`nnValue` 有维度保护会回退手工）。
7. Node 需 22+（引擎用了 iterator helpers）。
8. 4 vCPU ≠ 4 物理核（16 vCPU ≈ 8 核吞吐）。
9. ssh 里 heredoc 容易被吞 → 本地写脚本再 scp。
10. 小批量 MLP 必须单线程 BLAS（`OPENBLAS_NUM_THREADS=1`）。
11. 采集与实验抢 CPU，两边都会慢约 2 倍。
12. `ab-value.mjs` 的 `draw` 以前从不自增（和棋会让 `games` 少算）——今天已修。
13. `packages/ai` 在 `gi-tcg` 里是未跟踪目录（`?? packages/ai/`）；只有 `packages/core` 的改动会出现在 git 里。
