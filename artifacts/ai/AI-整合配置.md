## 一、开关的真实情况：9 个开关里只有 4 个真的接线

`ai-flags.ts` 定义了 9 组开关，但只有 4 个真的传到了 AI 决策链（`StandaloneParent.tsx:619-623`）：

| 开关 | 是否生效 | 说明 |
|---|---|---|
| `search.enabled` / `search.budgetMs` | ✅ 生效 | 控制推演搜索开关与预算 |
| `valueNet.enabled` | ✅ 生效 | 控制价值网络参与叶评估 |
| `valueTable.enabled` | ✅ 生效 | 控制查表价值（但表数据从未装载） |
| `memory.enabled` | ⚠️ **装饰** | 只影响 UI 文字，不进决策 |
| `priors.enabled` | ⚠️ **装饰** | 同上 |
| `policyNet.enabled` | ⚠️ **装饰** | 同上 |
| `twinNet.enabled` | ⚠️ **装饰** | 模型未实现 |
| `bayes.enabled` | ⚠️ **装饰** | 未实现，且数据基础今天才修好 |
| `llm.enabled` | 独立功能 | 只做解说，不参与下棋 |

**结论：真正需要决策的只有 search / valueNet / valueTable 三项。**

## 二、推荐配置（按实测收益）

| 组件 | 状态 | 依据 |
|---|---|---|
| 规则引擎 | **必开**（无开关） | 地基，合法动作与结算 |
| 启发式评估 | **必开**（无开关） | 兜底 + 搜索的候选先验 |
| **推演搜索** | **开，2500ms** | 104 局 **57.7%**，今天唯一正收益 |
| 价值网络 | **关**（可选开） | 1,040 局 +1.1 点，不显著；还会加推理开销 |
| 查表价值 | **关** | 59 万条落进 55 万个桶，桶内 ≥30 局的样本仅 3.8% |
| 决策记忆 | **关** | 3,592 次查询 **0 次命中**（局面指纹从不重复） |
| 经验先验 | 保持现状 | 关掉 51.3%，与开着无差异（±9.6%） |
| 策略网络 | **关** | 四种用法全部低于 50%：替代 35.6%、搜索标签 44.2%、去 sc 36.7%、引导搜索 46.9% |
| 双头网络 | **关** | 未实现；前提是搜索标签数据，正在采 |
| 贝叶斯读牌 | **关** | `e` 字段（对手已出牌）今天才修好，没有可用数据 |
| LLM 解说 | 可选 | 不影响棋力 |

**一句话配置：规则引擎 + 启发式 + 搜索，其余全关。**

## 四、离线诊断要点

- 数据：20,000 局 / 593,030 条 / 64MB，正样本率 50.01%
- 学习曲线：167 局 68.6% → 19,101 局 72.3%，**仍在上升**（但 A/B 证明不转化成功力）
- 精度分层：胶着局面 68%，已定局面 93~100%，前 2 回合 63% —— **整体准确率被"垃圾题"抬高**
- 先手优势：50.4% vs 49.6%，可忽略
- 结论：把准确率从 68% 推到 73% 的代价是 100 倍数据，而胜率不变 → **精度不是瓶颈**

2. **双头网络**：共享 trunk + 价值头/策略头，用上面这批数据训练
