# 七圣召唤 AI · 终结报告（2026-11-28）

> **封存声明**：AI 研究线于 2026-11-28 03:38 正式封存，不再迭代。
> App 内保留「搜索版」AI（默认 2500ms 预算）作为现有能力；DMC 不接入 App。

## 一、最终成绩单（全部为 AI 对 AI，镜像配对，0 出错）

| 对比 | 局数 | 胜率 |
|---|---|---|
| 搜索（150ms）vs 纯启发式 | 798 + 208 | **60.7% / 60.1%** |
| 搜索（600ms）vs 纯启发式 | 207 | **85.5%** |
| 跳过 rollout 预览 | 416 + 207 | **63.9% / 65.2%** |
| 600ms vs 150ms | 415 + 208 | **75.7% / 75.0%** |
| 猜牌（A 方案）vs 旧逻辑（App 等价配置） | 224 | **48.7%（打平）** |
| **DMC vs 纯启发式** | 224 | **67.6%** |
| **DMC vs 搜索 150ms** | 224 | **50.2%（打平）** |
| **DMC vs App 搜索 2500ms** | 224 | **28.7%** |
| DMC 自对弈 sanity | 224 | 52.2% |
| 框架对照 v1 vs v1 | 224 | 52.7% |

**一句话**：搜索版能稳定压过启发式，但打不过熟练玩家；DMC 用 0.1ms/手 换到了 150ms 搜索的强度，
打到 App 的 2500ms 搜索只有 28.7%——即使按曲线外推到 1,000 万局，预计也只有 ~37%。

## 二、为什么最终认输（诚实版）

1. **强度天花板低**：搜索版对启发式 60%，而这个游戏的"启发式"本身就打不过熟练玩家；
   所有数字都是 AI 对 AI，**从未验证过对真人**。
2. **隐藏信息**：搜索靠"确定化 + rollout"，对手手牌靠猜；我们的 A 方案让猜牌只用公开信息，
   但这也意味着搜索失去了最后一层"作弊红利"（48.7% 打平，说明红利本来就不大）。
3. **评估函数粗糙**：手工材料分 + 10 步深度，看不到蓄爆、斩杀线、留骰这些真人常识。
4. **训练信号**：价值网/策略网在 1,000+ 局上零收益，说明"监督/回归"路线学不到超越搜索的东西。
5. **DMC 的样本鸿沟**：DouZero 是 48 核 + 4 卡、百万局级；我们 13.5 万局只是零头。
   曲线在 70% 附近已经走平，外推 1,000 万局对 App AI 仍只有 ~37%。
6. **算力成本**：16 vCPU 按量 ¥2.04/小时，跑一天 ¥49；用算力硬堆强度的性价比极低。

## 三、失败清单（按主题，含具体数字）

| 方向 | 样本 | 结果 | 结论 |
|---|---|---|---|
| 价值网络（22/40 维） | 1,040 局 | 51.1%（+1.1 点，p≈0.25） | 离线精度 70% 不转化成功力 |
| 价值网 @600ms | 208 局 | 47.6% | 高预算下仍是零/负收益 |
| 策略网络（替代出招） | 396 局 | 35.6% | 明显弱于启发式 |
| 策略网络（搜索标签） | 199 局 | 44.2% | 仍弱 |
| 策略头引导搜索 | 207 局 | 46.9% | 拖累搜索 |
| 查表价值 | 59 万条 | 桶覆盖 3.8% | 数据太稀疏，不可用 |
| 决策记忆 | 104 局 | 命中 0 / 3,592 次 | 局面指纹从不重复 |
| 静态先验 / 学习先验 | 392 / 794 局 | 51.3% / 52.6% | ≈0 |
| rollout 深度 10→30 | 104 局 | 51.9% | 无差异（预算不变时加深没用） |
| 时间预算 150→80ms | 104 局 | 46.2% | 无差异 |
| 进化调权重 | 80 局 | 进化 87.5% → 独立验证 50% | 学的是噪声 |
| 后台预计算 | 52 局 / 4,239 手 | 命中率 0.59% | 不可用 |
| 早期样本加权 | 24 万条 | 胶着准确率 +0.02 点 | 无效 |
| **DMC 自对弈（35k 局）** | 224 | 对 App AI 28.7% | 未过 55% 门槛 |
| **DMC 扩样（+10 万局）** | 进行到 R4 即封存 | Q4 对启发式 71.1% | 曲线走平，外推不足以翻盘 |

**方法论层面的失败**：

1. **评测框架有 +2.5% 的 A 侧偏差**：sanity 与 v1-vs-v1 都落在 ~52.5%，说明镜像配对没有完全抵消
   首手/随机种子差异——以后所有 A/B 都要跑这个对照并做修正。
2. **小样本结论不可信**：128 局 sanity 曾出现 41.4%，224 局复测回到 52.2%；
   100 局误差 ±9.8%，任何 100 局结论都不能当决策依据。
3. **特征泄漏**：44 维特征里的 `deckPriorDiff` 曾读对手 `initialPile`（隐藏信息），
   已改为按角色公开估计；这类问题要定期审计"喂给 AI 的每一维是不是公开信息"。
4. **训练/评测路径 bug**：`--dmc` 权重路径被拼接两次导致快评 0 局、`ab-value` 和棋不计 `draw`、
   异步写流丢数据——长链实验必须带"失败即停 + 产物校验"。

## 四、有效的三件事（已上线或可复用）

1. **跳过 rollout 内动作预览**（+13.9 点，已上线 Worker）；
2. **搜索本身**（对启发式 +10~11 点）；
3. **大招计划**（缺骰时调和凑大招，+3.3 点）。

**核心规律**：强度几乎全部来自 rollout 次数，翻倍约 +12~13 点。

## 七、如果以后还想重启 AI

1. **先跑 sanity 对照**（同配置 50%），确认评测框架无偏差；
2. 目标定成"打赢 2500ms 搜索"而不是"打赢启发式"；
3. 优先走**混合**（DMC 当搜索先验/rollout 策略）或**蒸馏搜索**，不要从零扩样 DMC；
4. 任何改动上线前：≥208 局镜像配对 + 至少 2 个独立 seed 区间；
5. 数据/权重/日志一律归档（这次补做的 `artifacts/ai/dmc/` 就是模板）。
