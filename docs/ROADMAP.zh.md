# 路线图

按优先级排列，欢迎提 Issue 讨论。

## 近期

- [ ] **牌组库增量同步**：只抓新增牌组，避免全量重抓
- [ ] **实验室结果对比**：一次跑多套候选，表格对比克制率
- [ ] **对局复盘导出**：日志导出为可分享的文本/图片
- [ ] **训练器进度可视化**：训练曲线（每批胜率变化）

## 中期

- [ ] **AI 风格档案**：激进/稳健/控场三种出牌风格可选
- [ ] **牌组图模板**：多种分享图样式
- [ ] **多语言**：英文界面
- [ ] **平板布局**：大屏双栏（牌组库 + 对局预览）

## 远期

- [ ] **本地对局回放社区**：导出/导入 `.gitcg-replay` 文件
- [ ] **AI 对战 AI 的联赛模式**：跑循环赛出排行榜
- [ ] **Web 版 PWA**：浏览器可安装、离线可用

## 不做

- 不联网、不采集数据（这是产品底线）
- 不做自动化打真游戏（只做本地模拟）
- 不内置付费/广告
