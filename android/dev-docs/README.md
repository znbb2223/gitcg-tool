## 三、已知 BUG（短期不修）

1. **模拟器“先手/后手牌组”名不副实**：两个输入框实际控制的是人机 / AI 牌组，不是先手/后手。
   规避：按“我方牌组 / AI 牌组”理解，或进对局后用摆盘器改。
2. **组牌器竖屏卡牌右下角放大镜失效**：不能直接打开详情，但不影响选牌。
   规避：先把牌加入牌组，再点屏幕下方「当前牌组」里的同一张牌，即可看详情。

## 四、牌组码工具（非常规牌组）

README 首页那张“3 个相同角色 + 30 张相同卡”的牌组图，是用 `tools/deckcode/` 生成的
**非常手段**牌组，不是正常可对战牌组。

| 文件 | 平台 |
|---|---|
| `deckcode.sh` | Android sh / Termux / dash / mksh |
| `deckcode.bat` | 纯 cmd（Winlator / Wine） |
| `deckcode-windows.bat` | Windows 10/11 |
| `deckcode.html` | 浏览器，可编辑 33 槽 |

牌组码固定 **33 槽 = 3 角色 + 30 行动牌**；同名卡正常最多 2 张、角色不能重复。
改了卡牌数据后，记得同步这四个文件里的 `id|shareId|中文名` 表。
